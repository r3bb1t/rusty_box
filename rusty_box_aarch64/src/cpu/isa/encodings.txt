# The A64 encodings the rusty_box AArch64 interpreter decodes.
#
# `cargo xtask a64-decode` compiles this list into table.rs beside it
# (xtask/src/a64_decode.rs gives the syntax); `cargo xtask ci` fails while the
# two disagree.
#
# Source. Each `class` section is an encoding class of the A64 encoding index
# of the Arm Architecture Reference Manual for A-profile (DDI 0487, chapter C4,
# "A64 Instruction Set Encoding"), named by the `Class` variant whose handler
# executes it and followed by the class's bit diagram, ARMv8.0 field names,
# bit 31 first. Each row under it is one encoding of that class, its fixed
# bits split at the diagram's fields, and its mnemonic. The generator refuses
# a row that does not keep every bit its class's diagram fixes.
#
# Granularity. A word decodes to the matching row with the most fixed bits,
# and the generator refuses a list in which that rule could name two rows.
# Rows are cut where binutils' opcode table (opcodes/aarch64-tbl.h) cuts them,
# so that the exhaustive equivalence test (src/cpu/decode.rs) can compare every
# encoding with disarm64's, which is generated from that table, one to one.
# Where that table fixes a bit the Arm ARM's diagram leaves to the decode
# pseudocode — Q for a narrowing instruction's "2" form, size for a scalar
# form defined at one size, a should-be-one field — the word it leaves out is
# one the pseudocode makes UNDEFINED (or, for a should-be field, one for which
# UNDEFINED is a permitted CONSTRAINED UNPREDICTABLE behaviour), so deciding
# it here instead of in the handler changes nothing a guest can see.
#
# Cross-checks. disarm64 0.2, over all 2^32 words (src/cpu/decode.rs,
# `the_classifier_matches_disarm64_on_every_word`): every word disarm64 names
# an encoding of an advertised feature for, this list names the same encoding;
# every other word is UNDEFINED; the exceptions are the HINT space and the two
# disarm64 tagging faults that test names. And QEMU 11.1.2's decoder
# (target/arm/tcg/a64.decode), sampled when this list was written: the row
# instances QEMU decodes, it decodes to the same instruction, and every row
# instance it leaves unallocated is UNDEFINED here too — a reserved value the
# class's handler rejects.
#
# `absent` sections list encodings of features this processor does not have:
# an encoding of a later architecture that takes precedence over an ARMv8.0
# row sharing its fixed bits, or an optional ARMv8.0 extension named before it
# has a handler. Each is UNDEFINED.
